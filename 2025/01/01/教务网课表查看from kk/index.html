浙江大学教务网课表查看相关api的解析

本文档是对之前的解析的重写，这次换用了md来增强可读性

（别问为什么不用postman写api文档，因为笔者写不来）

由于依然有部分的内容无法理解且均保持为常值，所以只能尽力给出所有理解的部分，见谅。如果有能推测出对应意思的，也欢迎修改指正。

为了方便，部分个人信息没有抹去，各位就随便看看吧

1.调用接口

http://zdbk.zju.edu.cn/jwglxt/kbcx/xskbcx_cxXsKb.html?gnmkdm=N253508&su=用户学号

  • gnmkdm：功能模块代码，保持N253508不变即可
  • su：学生的学号

同时，需要用POST传递如下的表单数据：

变量名 代指 内容参考
xnm 学年名 2024-2025
xqm 学期名 1|秋（需要编码，这里已经解码了）
xqmmc 学期名名称 秋
xxqf 未知 0
xsfs 显示方式？ 0
注意，xxqf和xsfs不太能确定其含义，但推测与有效信息无关

2.返回内容

返回内容为一个JSON文档，下文中仅对预计有用的变量进行了标注，一些与页面显示相关的变量就先行忽略了

  • xzb: 工科试验班2416 // 行政班
  • xy: 求是学院蓝田学园 // 学园
  • ywkList: [] // 不清除，但一般空置（我没测试出代值的情况）
  • kbcdList:
    • kbcd: 5 // 课表长度表：5 5 3分别代表早5，下5，晚3（我佛了woc）
    • kbcd: 5
    • kbcd: 3
  • kbList // 这个是主要课表的存储位置，仅仅给出一个课表来解析，完整的请看范例文件
    • completeAnswer: true // 不清除，但没有看到false
    • djj: “6” // 第几节（我傻了）
    • dsz: “2” // 单双周
    • jgpxzd: “1” // 课程评估状态（不确定，目前看到的所有课程均为1）
    • jszgh: “0822226” // 教师职工号（相同老师的课这个属性相同,但我暂时查不到老师的编号）
    • kcb: “无线电测向（初级）
      秋冬{第1-8周|1节/周}
      朱玲
      紫金港田径场（东）zwfzwf” // 课程信息，用来显示在课程表中，同时如果有期末考试的课最后好像会写明考试时间
    • listnav: “false” // 一个插件的名字，估计是禁止筛选（这个插件是给用户提供筛选功能的，具体不了解）
    • localeKey: “zh_CN” // 略（页面表格相关）
    • pageable: true // 略（页面表格相关）
    • queryModel // 略（页面表格相关）
      • currentPage: 1
      • currentResult: 0
      • entityOrField: false
      • limit: 15
      • offset: 0
      • pageNo: 0
      • pageSize: 15
      • showCount: 10
      • sorts: []
      • totalCount: 0
      • totalPage: 0
      • totalResult: 0
    • rangeable: true // 略（页面表格相关）
    • rsdzjs: 0 // 无法推测，目前来看所有课都是0
    • sfqd: “1” // 是否确定（判断选课是否确定，用于显示蓝色红色！）
    • skcd: “1” // 上课次第（与上面KCB中的X节/周对应，注意，似乎习题课与其他课时分开显示的）
    • totalResult: “0” // 略（页面表格相关）
    • userModel // 略（页面表格相关）
      • monitor: false
      • roleCount: 0
      • roleKeys: “”
      • roleValues: “”
      • status: 0
      • usable: false
    • xkkh: “(2024-2025-1)-PPAE0051G-0822226-4” // 选课课号，格式为学期-课程编号-职工号-课程数（我们老师开了4节测向课）
    • 星期几: “1” // 数字代表礼拜几
    • xxq: “秋冬” // 学期区，标注课程经过的学期，如“秋冬”“冬”等
  • sjklist // 实践课课程（显示在页面上方）
    • completeAnswer: true
    • jgpxzd: “1”
    • listnav: “false”
    • localeKey: “zh_CN”
